4. CÁCH THÊM ẢNH VÀO PROPOSAL
───────────────────────────────────────────────────────────────

  Bước 1: Capture screenshot từ Base CRM (hoặc bất kỳ nguồn nào)

  Bước 2: Đặt tên file ĐÚNG CHÍNH XÁC như danh sách trên
          (chú ý: chữ thường, dấu gạch ngang, đuôi .png hoặc .jpg)

  Bước 3: Copy file vào folder "images/" trong folder proposal

  Bước 4: Refresh trang web (Ctrl + F5 / Cmd + Shift + R)
          → Ảnh tự động hiển thị thay placeholder

  LƯU Ý: 
  - Nếu file chưa có ảnh → hiển thị placeholder đẹp với hướng dẫn
  - Có thể thêm ảnh dần dần, không cần đủ ngay từ đầu
  - Refresh trang sau khi thêm để thấy thay đổi


5. KHUYẾN NGHỊ KỸ THUẬT KHI CHỤP SCREENSHOT
───────────────────────────────────────────────────────────────

  • Kích thước: ~1440×900 hoặc 1920×1080 px
  • Format:     PNG (chất lượng cao) hoặc JPG (nhẹ hơn)
  • Crop:       Không cần lấy thanh URL trình duyệt
                Code đã có khung browser giả bao quanh
  • Dữ liệu:    Dùng demo data nhìn "thực" 
                (tên khách hàng/số liệu thuyết phục)
                Tránh "test test test"

───────────────────────────────────────────────────────────────

  Mở file "index.html" bằng:
